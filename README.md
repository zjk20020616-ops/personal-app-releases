# App 发布中心

Free public download center for signed personal Android apps.

- Website: `https://zjk20020616-ops.github.io/personal-app-releases/`
- Stable release tag: `latest`
- APK source code and signing credentials are not stored in this public repository.

The bookkeeping app is built in its private repository and uploads signed artifacts here through a repository-scoped token. Mercado Perenne uses the same fixed signing certificate.
